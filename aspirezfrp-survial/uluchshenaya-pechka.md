# Улучшеная печка

Вот перевод текста на русский язык:

***



Печи, Плавильные печи и Коптильни можно зачаровывать. Костры (лагерные костры) нельзя зачаровать, так как они работают бесконечно, но медленнее. Зачарования **не переносятся**, если печь используется для крафта Плавильной печи или Коптильни.

***

#### Зачарования

**Эффективность (Efficiency)**

Увеличивает скорость переплавки предметов. Из-за ускорения работы топливо расходуется быстрее.\
**Формула:**\
`время переплавки = базовое время * (1 + уровень / (2 + |уровень|))`

| Уровень зачарования | Секунд на 1 предмет |
| ------------------- | ------------------- |
| 0                   | 10                  |
| 1                   | 6.7                 |
| 2                   | 5                   |
| 3                   | 4                   |
| 4                   | 3.3                 |
| 5                   | 2.9                 |

***

**Прочность (Unbreaking)**

Увеличивает продолжительность горения топлива.\
**Формула:**\
`длительность горения = базовая длительность * (1 + уровень / (3 + |уровень|))`

| Уровень зачарования | Уголь (сек.) | Огненный стержень (сек.) | Ведро лавы (сек.) |
| ------------------- | ------------ | ------------------------ | ----------------- |
| 0                   | 80           | 120                      | 1000              |
| 1                   | 100          | 150                      | 1250              |
| 2                   | 112          | 168                      | 1400              |
| 3                   | 120          | 180                      | 1500              |

***

**Удача (Fortune)**

Дает шанс получить больше продуктов переплавки.\
**Формула:**\
`среднее количество = (уровень + 1) / 2 + 1 / (уровень + 2)`

| Уровень зачарования | Среднее количество |
| ------------------- | ------------------ |
| 0                   | 1                  |
| 1                   | 1.33               |
| 2                   | 1.75               |
| 3                   | 2.20               |

***

**Шелковое касание (Silk Touch)**

* Печь с этим зачарованием **перестает расходовать топливо**, когда не используется. Как только в нее помещают предмет для переплавки, работа возобновляется.
* При разрушении и повторной установке печи **оставшееся топливо не сохраняется**.
